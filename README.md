# One Emoji, One Dream Vacation

Submits a single emoji as a dream vacation. `main.py` writes the entry to
`$OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, and
prints `LEN=<n>`.

Run:

```sh
OUTPUT_DIR=/tmp/o python3 main.py
```
